Don't have the extension yet? It's not on the Chrome Web Store, so it has to be added by hand — takes about a minute, follow the pictures below exactly and you can't go wrong.

⬇ Download extension (.zip)
1Unzip the downloaded file
revm2-extension.zip
revm2-extension (folder)

Double-click the .zip to unzip it. Keep the resulting folder somewhere permanent (like Documents) — don't delete it later, Chrome reads the extension straight from it.

2Open the extensions page
chrome://extensions

Copy chrome://extensions (or edge://extensions if you use Edge) into your browser's address bar at the top and press Enter.

3Turn on Developer mode
Off
On

There's a "Developer mode" switch in the top-right corner of that page. Click it once so it turns gold/blue like the "On" example above.

4Click "Load unpacked"
Load unpacked
revm2-extension

Three new buttons appear once Developer mode is on — click Load unpacked, then pick the unzipped revm2-extension folder from Step 1.

That's it — the extension icon will appear in your browser toolbar. Come back to this tab and hit the button below.
